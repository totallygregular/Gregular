# Leveling planner demonstration

Run `npm ci --ignore-scripts` and `npm run dev`, then open **http://127.0.0.1:5173/**. Use the same browser and origin throughout. This scenario creates example user input; no Troll Priest is saved as default profile data.

1. Enter a new local username, for example **planner-demo**. Create a character with your chosen name, race **Troll**, class **Priest**, faction **Horde**, current level **24** and progression status **Leveling**. Leave sample objectives unchecked. Open the character and select **Leveling**.
2. Under **Choose starter route**, select **Horde starter · 20–30** and press **Merge starter**. The roadmap contains Stonetalon Mountains, Ashenvale and Hillsbrad Foothills with editorial personal windows. The source confirms zone activity, not these planning levels or a quest-chain order.
3. Inspect **Current bracket**, **Earlier levels** and **Later levels**. The current view covers level 24 through 32. Stonetalon's 20–24 window overlaps level 24; Ashenvale's 24–27 and Hillsbrad's 27–30 plans are also visible. Edit any window to match your own route. Use the up/down arrows to change order and **Save name** to rename the route.
4. Edit **Ashenvale**. Set **Status** to **Active**. If you have checked your character's access, select **I confirmed access** under **Access / readiness**, then **Save objective**. Otherwise leave **Needs review**: it remains in the roadmap without being offered as immediately actionable. A readiness choice is user input, not a new verified game fact.
5. Choose **Add objective**. Keep **Personal objective**, enter **Check my Priest trainer**, set **Priority** to **High**, target levels **24–24**, and optionally associate it with a zone. Save it. This is your task; Gregular is not asserting that a particular ability unlocks at level 24.
6. Choose **+ Dungeon milestone**, then select **Excavation Site: Wetlands** under **Forever reference (optional)**. Its published beta band is 26–31; its entry minimum and quest prerequisites remain unknown. Rename the title to **Arrange an Excavation Site run** if desired, add your own notes and save. Only choose **I confirmed access** after your own review; leave uncertain access as **Needs review**.
7. Open **Quest journal**. **Next Up — Level 24** includes your unfinished eligible plans. Confirmed active Ashenvale is prioritised; the high-priority trainer task appears. A confirmed dungeon plan starting at 26 is **Coming up**. An unconfirmed entry remains a review item in the roadmap.
8. Complete **Check my Priest trainer** using its Next Up check button or change its roadmap status to **Completed**. It disappears from actionable Next Up and remains recorded as completed. Try **Skipped** on an optional route entry: it is retained without being recommended. Reopen its status to **Planned** if you want to resume it.
9. Return to **Leveling**, press **Update level**, change the character to **26**, and save the character. The bracket becomes 26–34. Your confirmed level-26 dungeon plan can now appear in Next Up; if access is unconfirmed, the review gate still applies. Changing level never resets completion or invents new goals.
10. Reload. The same character level, route name/order, notes, statuses and objectives should remain. Switch to another character or username and back: each route stays separate. Use **Export local profile** to keep a schema-2 JSON copy outside the browser; import/restore is deferred.

To try template restoration, remove an unneeded starter zone, add a personal objective, and merge the same starter again. Missing starter entries are added; your existing edited entries, completed/skipped states and personal objectives remain. Removing an entry removes that entry's own progress, so cancellation or a prior export is useful if you are experimenting.

No part of this demonstration requires finishing every zone. [Progression data](progression-data.md) explains the reference limits; [validation](validation.md) records the automated and visual checks.
